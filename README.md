# Enterprise IT Skills Lab

A free, static learning dashboard for the six-month Enterprise IT Solutions Consultant development plan.

## Run it on Windows
1. Download and extract this ZIP.
2. Open the extracted `enterprise-it-skills-lab` folder.
3. Double-click `index.html` to open it in Chrome or Edge.
4. Your progress is saved in that browser on that computer.

No Node.js, package manager, API key, database, subscription or paid template is required. The Google Fonts import is optional; the site uses fallback fonts if offline.

## Publish free with GitHub Pages
1. Create a **new, separate public repository** named `enterprise-it-learning-hub` under `victorandreweyong-lab`.
2. Upload the contents of this folder to the repository root (the files `index.html`, `styles.css`, `data.js`, and `app.js` must be at the top level).
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish. The expected address is:
   `https://victorandreweyong-lab.github.io/enterprise-it-learning-hub/`

Do not put this website source inside your existing `cloud-engineering-portfolio` repository. Keep that repository for technical project evidence.

## Progress and privacy
Progress is stored in browser localStorage. It is not automatically synced across devices or browsers. Use **My progress → Export progress** to save a JSON backup, then **Import progress** on another device/browser.
